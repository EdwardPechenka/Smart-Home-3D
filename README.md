Smart Home Management System with 3D Visualization
Кросплатформний програмний комплекс для моніторингу та керування системами «Розумного будинку». Проєкт поєднує в собі ієрархічну модель IoT-пристроїв, інтерактивне 3D-середовище та систему аналізу енергоефективності в реальному часі.
🌟 Ключові особливості (Features)Інтерактивна 3D-візуалізація: Використання Qt Quick 3D для рендерингу моделі будинку у форматі .glb.Динамічні HUD-інтерфейси: Інформаційні мітки (Security Bubbles) автоматично перераховують свої координати ($x, y, z$) при обертанні камери, забезпечуючи стабільну прив'язку до об'єктів.Моніторинг енергоспоживання: Розрахунок поточного навантаження мережі в кВт на основі індивідуальних профілів потужності кожного приладу.Автоматизовані сценарії: Реалізація режимів «Ранок» та «Вечір» для групового керування пристроями (освітлення, клімат, побутова техніка).Мережева стійкість: Імітація ієрархічної залежності пристроїв від стану Wi-Fi роутера та Ajax Hub.Інтеграція з REST API: Отримання актуальних метеоданих через сервіс Open-Meteo у форматі JSON.Локальна база даних: Ведення детального логу подій та історії інцидентів у SQLite.
