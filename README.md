Smart Home Management System with 3D Visualization
Кросплатформний програмний комплекс для моніторингу та керування системами «Розумного будинку». Проєкт поєднує в собі ієрархічну модель IoT-пристроїв, інтерактивне 3D-середовище та систему аналізу енергоефективності в реальному часі.
🌟 Ключові особливості (Features)
Interactive 3D Visualization: High-fidelity 3D house model rendering using Qt Quick 3D (GLB format).
